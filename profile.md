# Профиль фрилансера

> Это контекст для генерации откликов. Чем подробнее и конкретнее — тем человечнее
> и точнее получаются черновики. Дополни своими кейсами, цифрами и ссылками.

**Кто я:** Fullstack-разработчик. Делаю веб-проекты под ключ и дорабатываю
существующие: бэкенд, фронтенд, интеграции, автоматизация.

**Стек:**
- Backend: PHP (Laravel, Yii2), Python (скрипты, API), MySQL
- Frontend: Vue.js, Nuxt, React, Node.js
- Битрикс / Битрикс24: разработка и доработка, интеграции
- Интеграции: REST API, сторонние сервисы, Telegram-боты
- Инфраструктура: Docker, DevOps, деплой

**Что делаю особенно хорошо:**
- Интеграции по API между сервисами (CRM, платёжки, маркетплейсы и т.п.)
- Telegram-боты и автоматизация рутины
- Парсинг данных и скрипты
- Доработка и поддержка действующих сайтов и веб-приложений

**Как работаю:** обсуждаю задачу до старта, предлагаю варианты решения, держу в
курсе по ходу. Сроки и стоимость — после уточнения деталей.
